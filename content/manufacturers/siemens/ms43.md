# MS43

BMW E46 6-cylinder petrol ECU. OpenRemap **identifies** it (Siemens /
MS43 — e.g. program number `430069`, Siemens part `5WK90027`) and
**verifies** its checksums.

| | |
|---|---|
| Era | 2001–2006 |
| File sizes | 512 KB |
| Vehicles | BMW E46 6-cylinder petrol |
| Extractor | SiemensMS43Extractor (STRONG, evidence-based) |
| Match key | `MS43::<program number>` (e.g. `MS43::430069`) |

**Identification:** the literal `MS43` family string + `5WK9` Siemens part
prefix at the exact 512 KB size gate (disambiguated from Simtec56, which
shares the `5WK9` prefix, by size).  `identify` reports HIGH confidence.

**Checksums:** full coverage — boot / program / calibration CRC-16/ARC
over descriptor tables, cracked from boot-code disassembly. The 32-bit
monitor sums are runtime checks and are reported as unverified. See
[Checksums command docs](../../checksum/cli.md).
