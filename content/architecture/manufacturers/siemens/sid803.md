# SID 803 / SID 803A

| | |
|---|---|
| Era | mid-2000s onward |
| File sizes | 458,752 or 462,848 bytes (SID803), 2,097,152 bytes (SID803A) |
| Engines | 2.0/2.2 HDi |
| Vehicles | Peugeot/Citroën (407, 607, C5), Ford, Jaguar/Land Rover |

## Detection

A size gate over exactly three sizes — 458,752, 462,848 and 2,097,152 bytes —
then the `PO` / `111PO` / `S122` positive signatures, with a `PM3` exclusion
(`PM3` means SID801, never SID803).

**Checksums:** no family profile (generic sweep only).
