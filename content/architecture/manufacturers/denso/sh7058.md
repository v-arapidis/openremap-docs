# SH7058

The Denso **SH7058** (SuperH) CAN ECU used in 2006–2014 Subaru models.
This 1 MB family was previously mislabelled *SH72531*; it was renamed in
0.7.6 to the correct CPU.

| | |
|---|---|
| Era | 2006–2014 |
| File sizes | 1 MB |
| CPU | SuperH (32-bit CAN) |
| Vehicles | Impreza/WRX/STi, Forester, Liberty/Legacy, Outback, Tribeca, XV |

## Detection

Descriptor `34 A1/A2 00 0X` at 0x1FFC; CAL ID at 0x2000 (A1) or 0x2004 with an `FF FF 20 4C` prefix (A2); a few dumps are shifted by file-size − 1 MB.

**Checksums:** descriptor-table checksum (0x5AA5A55A, end-inclusive) — verified on 276/329 CAN ROMs.
