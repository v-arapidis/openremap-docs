# Denso

Four families of Denso ECUs running **Subaru** firmware, 2001–2014. All
are identified by an 8-character calibration ID (CAL ID) — the same
identifier the Subaru tuning community uses as its primary reference.
Family names follow the CPU labels (renamed to the correct CPUs in 0.7.6).

| Family | Era | File sizes | Vehicles & applications | Page |
|---|---|---|---|---|
| **68HC16Y5** | 2001–2004 | 160 / 192 KB | Impreza/WRX/STi, Forester, Liberty (16-bit HC16) | [68HC16Y5](hc16y5.md) |
| **SH7055** | 2004–2007 | 512 KB | Liberty/Legacy GT, Forester XT, Impreza (SuperH) | [sh7055](sh7055.md) |
| **SH7058** | 2006–2014 | 1 MB | Impreza/WRX/STi, Forester, Legacy, Outback, Tribeca, XV (SuperH CAN) | [sh7058](sh7058.md) |
| **EE20 Diesel** | 2009–2012 | 1 MB | Forester/Impreza 2.0D boxer diesel | [diesel](diesel.md) |
