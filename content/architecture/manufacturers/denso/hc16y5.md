# 68HC16Y5

The Denso ECU inside 2001–2004 Subaru models is built around the Motorola
**68HC16Y5** (HC16) 16-bit CPU — not the SuperH chips of the later
families. Before release 0.7.6 this family was mislabelled *SH7055* (one
CPU generation off); the 16-bit units are Motorola HC16, so they are never
disassembled as SuperH.
