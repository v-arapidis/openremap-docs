# SH7055

The Denso **SH7055** (SuperH) ECU used in 2004–2007 Subaru models
(Liberty/Legacy GT, Forester XT, Impreza). The 512 KB unit was previously
mislabelled *SH7058*; it was renamed in 0.7.6 to the correct CPU.

| | |
|---|---|
| Era | 2004–2007 |
| File sizes | 512 KB |
| CPU | SuperH (32-bit) |
| Vehicles | Liberty/Legacy GT, Forester XT, Impreza |

## Detection

4-byte descriptor (`31 91 00 05`) at 0x1FFC, CAL ID at 0x2000, internal ID at 0x2009, `Copr.DENSO` anchor.

**Checksums:** none in corpus — defs place a table only for specific CAL IDs.
