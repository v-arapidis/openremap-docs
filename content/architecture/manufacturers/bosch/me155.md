# ME1.5.5

Bosch **ME1.5.5** (1999–2005) powers Opel/Vauxhall petrol ECUs such as
the Astra-G Z20LET and Corsa-C Z12XE/Z12XEP. It runs on an
Infineon/Siemens **C167CR** CPU with a 512 KB external flash — the same
size and ZZ ident offset (0x10000) as ME7, which is why it is a separate
extractor registered just before ME7.

| | |
|---|---|
| Era | 1999–2005 |
| File sizes | 512 KB |
| CPU | Siemens C167CR |
| Vehicles | Opel/Vauxhall petrol (Astra-G Z20LET, Corsa-C Z12XE/Z12XEP) |

## Detection

Size gate + ZZ descriptor at 0x10000 whose byte at 0x10002 is a printable
ASCII character (`0x34` = `4`) — ME7 has non-printable bytes there
(`0xFF`/`0x00`/`0x01`) — plus the `/ME1.5.5/` family anchor in the ident
window.

**Checksums:** no family profile.
