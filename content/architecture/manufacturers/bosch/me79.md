# ME7.9.x (ME7.9.10)

ME7.9.x is a later sub-generation of the ME7 family (also written
**ME7910** in flash markers and **ME7.9.1** in tuning nomenclature). It
covers the Fiat/Alfa/Lancia **1.4 T-Jet** and PSA variants from 2006
onwards — 832 KB dumps that the classic ME7 extractor deliberately skips,
because their ident block uses the `ZZ<<` dialect while ME7's guard only
accepts `ZZ` + an ASCII digit. In 0.7.6 ME7.9.x became its own Bosch
family, registered right after ME7 with no detection reordering anywhere
else.

| | |
|---|---|
| Era | 2006+ (Fiat/Alfa/Lancia 1.4 T-Jet, PSA variants) |
| File sizes | 832 KB (851,968 bytes) |
| Match key | `ME7.9.10::<sw>` |
| Hardware number | `0261…` / `0261S…` |
| Software version | 10-digit `1037…` |

## Detection

Ident block at 0x10000 starting with the `ZZ<<` dialect (real dump:
`ZZ<<ERCSU V1.1.6 SAB_C16x (c)ETAS Jul 24 1997`), plus a slash-delimited
family marker such as `45/1/ME7910/9/F200M144//3207C/07C1F00/171007/` in
the calibration area.

**Checksums:** no family-specific profile (generic sweep only).

Run [identify](/cli/look-at-a-file#identify) or [analyze](/cli/look-at-a-file#analyze)
to detect such a file.
